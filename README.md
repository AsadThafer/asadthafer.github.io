## Website

This is a static website built with HTML, CSS, and vanilla JavaScript and published using GitHub Pages.

To run it locally, clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/asadthafer/asadthafer.github.io.git
cd asadthafer.github.io
```

The site does not require a build step. Keep the `assets/` directory alongside the HTML, CSS, and JavaScript files so images and certificate previews load correctly.
